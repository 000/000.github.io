# Mobile App Policies & Legal Documents

This directory hosts static HTML documents—such as Privacy Policies, Terms of Service, and Data Deletion instructions—required for submitting and maintaining iOS and Android applications on the **Apple App Store** and **Google Play Store**.

All files in this directory are published via GitHub Pages to provide permanent, publicly accessible URLs for app store review teams and end users.
