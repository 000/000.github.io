Borrow to Learn · B2L

Data deletion

Clear local app data, manage separate copies and contact us about identifiable support or provider data.

Effective / มีผลตั้งแต่ 2026-10-15 · iOS and Android · Version 1.0

Remove the data you choose

B2L version 1.0 has no B2L user accounts. There is no registration, login or cloud bookmark account to close. This page explains the separate local, shared and provider-side deletion paths.

  1. Remove a saved story. Open Saved and tap the active bookmark for that story, or tap its active bookmark from the story. Other bookmarks and preferences remain.
  2. Clear Android app data. Open Android Settings → Apps → Borrow to Learn → Storage (wording varies) → Clear storage / Clear data. This resets B2L's local bookmarks, language and appearance. Uninstalling also removes its app sandbox.
  3. Remove iPhone app data. Open Settings → General → iPhone Storage → Borrow to Learn → Delete App. Choose Delete App; Offload App preserves documents/data. Removing only the Home Screen icon does not delete the app.
  4. Remove exports and backups separately. Delete CSV files or shared text from Files, Downloads, email, cloud drives and other destinations you used. Manage operating-system backups and transferred device copies through the relevant device/provider settings. Deleting B2L does not revoke copies held by other recipients.
  5. Ask about support data. Email la@defense.engineer with subject “B2L data deletion request”. Identify the support message or data you mean, preferably using the same email address. Do not send financial records, passwords or identity documents. We will explain any information reasonably needed to locate the record and any lawful retention limit.

Android Firebase identifiers are a separate category

The Android SDK can automatically register an installation. Clearing storage, uninstalling or disabling notification display does not confirm deletion of its provider-held identifier records. B2L 1.0 has no Firebase-ID display or API deletion control. Deleting an old provider record does not prevent an active or reinstalled SDK from creating a new identifier. Contact support about the relevant data and available provider process; we cannot promise deletion of an unidentified record or of every provider backup. See the Android SDK disclosure and Firebase installation-deletion documentation.

What a request does not do

A support email does not automatically clear your phone or another app's files. Local clearing does not erase recipient copies, close an Apple/Google account or confirm remote Firebase deletion. If an account feature is added later, its account-deletion process must be added to the app and this page.

ลบข้อมูลตามขอบเขตที่ต้องการ

B2L รุ่น 1.0 ไม่มีบัญชีผู้ใช้ B2L ไม่มีการลงทะเบียน เข้าสู่ระบบ หรือบัญชีบุ๊กมาร์กบนคลาวด์ จึงไม่มีบัญชี B2L ให้ปิด การลบข้อมูลแต่ละส่วนแยกกันดังนี้

  1. ลบเรื่องที่บันทึก: เปิดบันทึกแล้วแตะบุ๊กมาร์กที่เลือกอยู่ของเรื่องนั้น หรือแตะจากตัวเรื่อง รายการอื่นและการตั้งค่ายังคงอยู่
  2. ล้างข้อมูล Android: เปิดการตั้งค่าเครื่อง → แอป → Borrow to Learn → พื้นที่เก็บข้อมูล → ล้างข้อมูล/ล้างพื้นที่เก็บข้อมูล ชื่อเมนูอาจต่างกัน ขั้นตอนนี้รีเซ็ตบุ๊กมาร์ก ภาษา และธีม การถอนแอปลบพื้นที่ข้อมูลแอปด้วย
  3. ลบข้อมูล iPhone: การตั้งค่า → ทั่วไป → พื้นที่จัดเก็บข้อมูล iPhone → Borrow to Learn → ลบแอป การเอาแอปออกแบบ Offload เก็บเอกสารและข้อมูลไว้ และการลบไอคอนจากหน้าจอหลักอย่างเดียวไม่ได้ลบแอป
  4. ลบไฟล์และข้อมูลสำรองแยก: ลบ CSV หรือข้อความที่ส่งไปยัง Files ดาวน์โหลด อีเมล คลาวด์ หรือปลายทางอื่นที่ใช้ จัดการข้อมูลสำรองและสำเนาที่ย้ายเครื่องผ่านการตั้งค่าผู้ให้บริการ การลบ B2L ไม่ได้เรียกคืนสำเนาของผู้รับ
  5. ขอลบข้อมูลช่วยเหลือ: ส่งอีเมลไป la@defense.engineer หัวข้อ “B2L data deletion request” ระบุข้อความช่วยเหลือหรือข้อมูลที่หมายถึง โดยใช้อีเมลเดิมถ้าทำได้ ไม่ต้องส่งข้อมูลการเงิน รหัสผ่าน หรือเอกสารยืนยันตัวบุคคล เราจะแจ้งข้อมูลที่จำเป็นเพื่อค้นหารายการ และข้อจำกัดการเก็บตามกฎหมายถ้ามี

รหัส Firebase บน Android แยกจากข้อมูลในเครื่อง

SDK อาจลงทะเบียนการติดตั้งอัตโนมัติ การล้างข้อมูล ถอนแอป หรือปิดการแสดงการแจ้งเตือนไม่ได้ยืนยันการลบรหัสที่ผู้ให้บริการเก็บ รุ่น 1.0 ไม่มีหน้าดูรหัส Firebase หรือปุ่มเรียก API ลบ การลบรหัสเดิมไม่ได้ป้องกัน SDK ที่ยังทำงานหรือติดตั้งใหม่จากการสร้างรหัสใหม่ โปรดติดต่อเรื่องข้อมูลและขั้นตอนที่ผู้ให้บริการรองรับ เราไม่รับรองการลบรายการที่ระบุไม่ได้หรือข้อมูลสำรองของผู้ให้บริการทุกชุด ดู นโยบายความเป็นส่วนตัว และ เอกสารการลบ Firebase installation

สิ่งที่ไม่ได้เกิดขึ้นโดยอัตโนมัติ

อีเมลขอลบไม่ได้ล้างมือถือหรือไฟล์ในแอปอื่นให้เอง การล้างในเครื่องไม่ได้ลบสำเนาผู้รับ ปิดบัญชี Apple/Google หรือยืนยันการลบ Firebase หากมีฟีเจอร์บัญชีในอนาคต ต้องเพิ่มขั้นตอนลบบัญชีจริงทั้งในแอปและหน้านี้
